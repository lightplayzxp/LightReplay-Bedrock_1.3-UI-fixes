## Is repo mein humne kya UI fixes kiye

### Normal Mode
- Normal Hub lock: Start Recording · Presets · Load Project · Switch Mode · Playback Options
- Start Recording → menu turant band
- Safe page (recording ON + wand): Save | Delete Progress | Simple Back
- Delete / Simple Back ke baad recording background mein nahi chalti
- Stop Playback se galti se naya record start nahi hota

### Advanced Mode — 4 Faces
- Face 1: Recording · Track Manager · Playback Options · Further Process · Load Project · Switch Mode
- Face 2: Free Cam · Track Manager · Playback Options (Night Vision only) · Further · Back
- Face 3: Keyframe tools · Master Timeline · Track Manager (no ripple) · Presets Coming Soon · Further · Back
- Face 4: Start Replay (bake) · Track Manager (no ripple) · Back — Stick Mode nahi

### Navigation
- Back = pichhla face only
- Further Process = agli face
- Wand = last face / recording pe Safe page
- Faces ghoomne se session auto-wipe nahi
